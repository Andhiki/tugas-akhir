# Reading list - Configuration Smells

Referensi utama yang menjadi dasar proposal:

1. [Configuration Smells in AGENTS.md Files](https://arxiv.org/abs/2606.15828) - taxonomy enam smell dan analisis prevalensi.
2. [Agent READMEs](https://arxiv.org/abs/2511.12884) - studi empiris file konteks agent pada banyak repository.
3. [On the Impact of AGENTS.md Files](https://arxiv.org/abs/2601.20404) - studi dampak keberadaan file terhadap efisiensi.
4. [Evaluating AGENTS.md](https://arxiv.org/abs/2602.11988) - evaluasi task success dan inference cost pada kondisi file konteks.
5. [SWE-bench](https://arxiv.org/abs/2310.06770) - benchmark task software engineering dari issue repository nyata.
6. [RepairAgent](https://www.software-lab.org/publications/icse2025_RepairAgent.pdf) - contoh AI agent untuk program repair.
7. [Understanding Software Engineering Agents](https://www.software-lab.org/publications/ase2025_trajectories.pdf) - dasar analisis trajectory agent.
