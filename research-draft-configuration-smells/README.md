# Draft Penelitian: Configuration Smells

Draft terfokus untuk judul utama:

> Evaluasi Dampak *Context Bloat* pada *Repository-Level Instruction Files* terhadap Kinerja dan Efisiensi AI Coding Agents

Dokumen ini mengikuti struktur proposal ringkas: latar belakang, rumusan masalah, tujuan, objek, metode, variabel, hipotesis, alur eksperimen, risiko, research gap, dan rencana kerja.

Compile dari folder ini dengan script kompilasi LaTeX pada repository utama. Output diletakkan di folder `build/`.

Dokumen kerja riset:

- `research-charter.md` — scope, research questions, hypotheses, dan keputusan riset terbaru.
- `literature-matrix.md` — pemetaan sumber dan gap yang sedang diverifikasi.
- `pilot-protocol.md` — protokol pilot untuk Context Bloat.
- `pilot-environment.md` — snapshot tooling lokal dan keputusan runner yang masih terbuka.
- `pilot-smoke-test-plan.md` — rencana smoke test yang executable tanpa langsung melakukan model call.
