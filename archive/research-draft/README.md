# Research Draft

Draft kerja untuk penelitian tentang deteksi ambiguitas requirement perangkat lunak menggunakan role-based multi-agent LLM.

Struktur folder ini disalin dari `proposal/` agar dapat dikembangkan tanpa mengubah proposal awal. Sumber utama ada di `main.tex`, dengan bab di dalam `chapters/` dan bibliografi di `references.bib`.

Build dari dalam folder ini:

```text
latexmk -pdf main.tex
```

Isi dokumen masih bersifat tentatif untuk diskusi bimbingan. Klaim literatur, dataset, pemilihan model, dan jadwal perlu dikunci kembali sebelum menjadi proposal final.
